# BluesCode

A VS Code extension providing AI-powered coding assistance with multi-mode architecture and comprehensive development tools.

## Project Overview

BluesCode that integrates multiple AI models to provide intelligent coding assistance. The extension features a multi-mode system allowing different specialized workflows for various development tasks, from code implementation to debugging and testing.

## Features

### Core Capabilities

- **Multi-Mode System**: Specialized modes for different development phases (Code, Debug, Architect, Test, Translate, Orchestrator)
- **AI Model Integration**: Support for Claude (Anthropic), GPT-4 (OpenAI), Gemini (Google), and other LLMs
- **MCP Server Support**: Model Context Protocol integration for external tool connectivity
- **Advanced Code Analysis**: Semantic search, definition mapping, and context tracking
- **Browser Automation**: Puppeteer-controlled testing and web interaction
- **Terminal Integration**: Command execution with safety controls and monitoring

### Tool Ecosystem

- File operations with intelligent diff strategies
- Codebase semantic search and analysis
- Real-time browser automation and testing
- Terminal command execution and monitoring
- Checkpoint system for project state management
- Context-aware code suggestions and completions

### Multi-Mode System

The extension implements a mode-based architecture:

- **Code Mode**: Implementation and refactoring
- **Debug Mode**: Systematic troubleshooting
- **Architect Mode**: System design and planning
- **Test Mode**: Jest testing and coverage
- **Translate Mode**: Localization support
- **Orchestrator Mode**: Multi-step project coordination

### Core Components

1. **Task Management**: Centralized task execution and state management
2. **Tool System**: Modular tool integration for various development operations
3. **Webview Interface**: React-based UI for extension interaction
4. **AI Integration**: Multi-provider AI model abstraction layer
5. **Context Management**: Intelligent context tracking and memory
